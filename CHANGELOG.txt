v4.0.0 (bioluks) - Renamed to TailMate

- Rename the project from KernelSU-Tailscaled to TailMate. The module id is now
  `TailMate` and its state lives in /data/adb/TailMate; the repository moved to
  https://github.com/bioluks/TailMate (old URLs redirect).
- Installing 4.0.0 over KernelSU-Tailscaled hands over automatically: the old
  `kernelsu-tailscaled` module is stopped, its node identity, settings and
  pending Taildrop files are copied (not moved) from /data/adb/kernelsu-tailscaled
  to /data/adb/TailMate, and the old module is marked for removal at the next
  reboot. No re-login is needed.
- The companion app is now `com.askingmeric.tailmate`, labelled TailMate. Android
  treats it as a new app: uninstall the old Tailscaled Companion
  (io.github.bioluks.tailscaled) and install the TailMate APK.
- The update feed is now update.json. update-kernelsu.json mirrors it so existing
  KernelSU-Tailscaled installs are offered 4.0.0.
- Detect the busybox of KernelSU, KernelSU-Next, Magisk and APatch. KernelSU and
  KernelSU-Next are verified on device; Magisk and APatch are expected to work
  but not yet verified.
- Clarify licensing: the bundled hev-socks5-tunnel helper is MIT licensed.
- Remove the unused KernelSU module store tooling (module.yaml, store workflow
  and submission scripts).
- Version code 40000000 advances v3.6.0_tailscale1.104.7; the engine stays at 1.104.7.

v3.6.0 (bioluks) - Companion module settings, in-app panel, and Taildrop history

- Add a native Module settings screen to the companion covering every module
  setting in the KernelSU WebUI: control server / Headscale sign-in, Taildrop
  folder, Tailscale DNS, system-wide DNS, runtime and engine updates, staged
  runtime apply, diagnostic records and legacy migration.
- Open the full panel inside the companion by default, with a back bar and
  back navigation through panel pages; Settings → Open full panel in browser
  restores the previous behavior. The companion starts the panel when needed.
- The companion now requests INTERNET for the loopback panel only; cleartext is
  limited to 127.0.0.1 and other links open externally. A blocked per-app
  network switch shows app settings, retry and browser options.
- Replace the companion's raw status text with a structured card: connection
  state with a colored indicator, MagicDNS name, Tailscale IPs, Taildrop,
  system DNS, mode and module version; only warnings and errors are callouts.
- Fix the runtime dying when the app that started it is removed from recents.
  Android kills an app's whole uid/pid process group, and control actions run
  from KernelSU Manager's WebUI or the companion landed the daemon in it.
  control.sh now leaves any per-app process group before starting anything.
- Replace the "last transfer" text at the bottom of the companion with a
  transfer history: sent, received, failed and cancelled files with peer and
  time, newest 100 kept on this device. Show all opens the full list with
  Clear. Settings → Transfer history (default on) turns recording off and
  offers to clear what is stored.
- The "another DNS redirect" warning now explains itself: status-json carries
  a detail with each foreign port-53 chain, whether it is active or dormant,
  the boot script or module that creates it, and its rules. Tap the warning in
  the companion or expand it in the WebUI.
- Warn when Android Private DNS is set to a specific provider (strict DoT),
  which bypasses system-wide DNS, and offer `private-dns-off` to switch it off
  on explicit confirmation. Automatic mode can fall back to plain DNS and is
  not flagged. status-json reports `systemDns.privateDns`.
- Version code 30060000 advances v3.5.0_tailscale1.104.7; the engine stays at 1.104.7.

v3.5.0 (bioluks) - Opt-in system-wide DNS through Tailscale

- Add opt-in system-wide DNS: redirect Android's port-53 queries to the
  tailnet nameservers from the coordination server (source-NATed to the node's
  tailnet address), serving MagicDNS and forwarded lookups for every app.
- Control it with `control.sh enable-system-dns` / `disable-system-dns` or the
  new WebUI toggle. It is off by default and never touches netfilter until
  enabled.
- Owned netfilter chains exclude tailscaled's socket-marked traffic and
  loopback; IPv6 falls back to rejecting port 53 when the kernel lacks IPv6
  NAT. Rules are removed when the daemon stops or the module is removed.
- Report the expected Android /etc/resolv.conf write failure as an accurate
  info diagnostic instead of a misleading health warning.
- Version code 30050005 advances v3.4.0_tailscale1.104.7.

v3.2.0 (bioluks) — Native Android compatibility & Built from Source

- Build Tailscale binaries completely from scratch from pinned upstream v1.104.2 source;
  no opaque pre-compiled blobs are used. Engine builds are 100% deterministic and reproducible.
- Retry unsupported optional strict-netlink setup on older Android kernels (such as 4.9)
  without changing normal modern-kernel behavior or masking real errors.
- Route cached control-plane DNS and standalone CLI lookups through Android's
  existing system resolver rather than assuming /etc/resolv.conf exists.
- Preserve fresh hostname and conservative DNS/route defaults across restarts
  before the first authenticated profile persists; retain existing user choices.
- Deliver compatibility engines through full module updates. Block standalone
  engine replacement and reject implicit downgrades from a newer saved engine.
  Compile out the upstream self-updater so it cannot overwrite patched binaries.
- Keep native TUN networking without occupying Android's VPN service slot;
  no AFWall dependency, device-specific route injection or SELinux disabling.
- VersionCode 30020000 upgrades v3.1.0 and the 30010001–30010003 local candidates.

Distribution updates (no APK/module version change)

- Publish independently signed GitHub Pages and Forgejo F-Droid repositories
  for stable companion APK updates, preserving the existing Android signer.

v2.0.0-beta.5 (historical prerelease)

Published 2026-09-07. Immutable Release:
https://github.com/WayneShao/KernelSU-Tailscaled/releases/tag/v2.0.0-beta.5
Full release log: docs/releases/v2.0.0-beta.5.md

- Renamed the source project to KernelSU-Tailscaled and adopted the independent
  kernelsu-tailscaled module ID. The legacy v1 update feed is preserved.
- Isolated persistent state and complete runtime generations from manager files.
  Standard ZIP installation verifies, activates, and publishes its own runtime
  and KernelSU panel/action entrypoints without post-install patch scripts.
- Added explicit copy-only login migration with stopped-owner checks, validated
  configuration, recoverable journals and a separate enable gate.
- Added serialized lifecycle commands, bounded probes, process start-time checks,
  visible failed/degraded states and same-engine activation rollback.
- Retain process records and sockets when a still-live process fails identity
  verification; block replacement instead of spawning duplicate TUN owners.
- Reject orphaned supervisor passes after they acquire the lifecycle lock,
  preventing an old generation from cleaning up a newly installed runtime.
- Added truthful native interface/address/route diagnostics, upstream health
  warnings, effective preferences and active/staged/previous runtime versions.
- Restricted configuration to validated data; bounded and redacted runtime logs.
- Corrected Android mksh descriptor inheritance and BusyBox JSON scalar parsing
  using actual shell/applet regressions discovered during device verification.
- Prepared universal-only, immutable official-store distribution gates. Store
  review and stable publication are separate from candidate builds.

Candidate validation and device results are recorded under docs/verification.
This beta is not a claim of broad compatibility or long-term network stability.
