# TailMate v4.0.0_tailscale1.104.7

KernelSU-Tailscaled is now **TailMate**. The runtime, WebUI and companion features are unchanged from v3.6.0; this release changes the project's identity.

## Coming from KernelSU-Tailscaled

- Install the TailMate ZIP in your root manager over the running KernelSU-Tailscaled module. Do not uninstall anything first.
- The installer stops the old `kernelsu-tailscaled` module, copies the node identity, settings and pending Taildrop files from `/data/adb/kernelsu-tailscaled` to `/data/adb/TailMate`, and marks the old module for removal at the next reboot. The old state is copied, not moved. No re-login is needed.
- The companion now has the package `com.askingmeric.tailmate` and is labelled **TailMate**. Android treats it as a different app: uninstall the old Tailscaled Companion (`io.github.bioluks.tailscaled`) and install the TailMate APK. Obtainium users should import the new entry from [the update channels page](../distribution/companion-updates.md).

## Identity and distribution

- Module id `TailMate`, state directory `/data/adb/TailMate`, repository [bioluks/TailMate](https://github.com/bioluks/TailMate) (old URLs redirect) and [execd/TailMate](https://git.dreamscape.one/execd/TailMate) on GitScape.
- The update feed is `update.json`. `update-kernelsu.json` mirrors it so existing KernelSU-Tailscaled installs are offered this release.
- The KernelSU module store tooling was removed; releases are published on GitHub and GitScape only.

## Managers and licensing

- The installer and runtime detect the busybox of KernelSU, KernelSU-Next, Magisk and APatch. KernelSU and KernelSU-Next are verified on device; Magisk and APatch are expected to work but are not yet verified on device.
- The bundled hev-socks5-tunnel helper is MIT licensed; LICENSE and NOTICE state this explicitly.

## Install

| Asset | Use |
| --- | --- |
| `TailMate-v4.0.0_tailscale1.104.7.zip` | Universal module ZIP (ARMv7 and ARM64) |
| `TailMate-arm64-v4.0.0_tailscale1.104.7.zip` | ARM64-only module ZIP |
| `TailMate-arm-v4.0.0_tailscale1.104.7.zip` | ARMv7-only module ZIP |
| `TailMate-companion-v4.0.0_tailscale1.104.7.apk` | Optional companion, Android 8.0 or newer |

Install one ZIP in your root manager. Install the optional companion separately with the release-signed APK. Version code **40000000** supersedes v3.6.0; the bundled Tailscale engine remains **1.104.7**.
