# TailMate v4.0.1_tailscale1.104.7

The companion app is now signed with the TailMate release key
(`CN=TailMate, O=Meriç Aşkın`, SHA-256
`3e3238fa4a9ecbcfb5c4bb6b3e7166ad5af3b6e667b02b2015e3cc966d9cd089`). This is
the key f-droid.org, the F-Droid channels, Obtainium and GitHub ship from now on,
so switching between them needs no reinstall.

The module, runtime and companion features are unchanged from 4.0.0.

## Updating

- **Module:** update normally; nothing to do.
- **Companion installed from 4.0.0:** Android cannot update across a signing key
  change. Uninstall the 4.0.0 companion once, install 4.0.1, and grant root again
  in your root manager. Settings and history in the app are reset.
- **Coming from KernelSU-Tailscaled:** install the TailMate 4.0.1 module ZIP; it
  hands over identity and settings as described in the 4.0.0 notes.
