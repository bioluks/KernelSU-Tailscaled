# KernelSU-Tailscaled v3.1.0 — Smoother Android sharing

The optional Android companion now opens a rounded device sheet over the app
that shared the files, instead of replacing it with a full-screen picker.
The source app remains visible behind a dimmed overlay.

## Changes

- Tap a device to send immediately. **Settings → Confirm before sending** adds
  an optional review step; it is off by default.
- **Settings → Language** offers English and Simplified Chinese. English remains
  the default, and the selection is remembered. The landing-screen language
  toggle is removed.
- Send notifications show the current file, sent bytes, known total size, and
  current KB/s or MB/s. Unknown or inconsistent provider sizes stay unknown.
- Independent sampling updates the rate during stalls. **Finalizing** remains
  cancellable and does not report success until the CLI finishes.
- Settings includes receive-notification controls and light/dark layouts.

Progress counts bytes supplied to the existing Tailscale CLI, not confirmed
remote receipts. No whole-file cache, second daemon, VPN slot or idle app polling
is added. Headscale support and module-owned automatic receiving are unchanged.
The bundled Tailscale engine remains **1.104.2**.

## Install

Install the matching module and optional APK from this release:

- `KernelSU-Tailscaled-v3.1.0.zip` — ARM and ARM64.
- `KernelSU-Tailscaled-arm64-v3.1.0.zip` — ARM64 only.
- `KernelSU-Tailscaled-arm-v3.1.0.zip` — 32-bit ARM only.
- `KernelSU-Tailscaled-companion-v3.1.0.apk` — Android 8.0+.

Install over the existing module; do not uninstall or delete its data first.
Version code **30010000** advances previous published and private combined builds.
The app uses the existing module connection and requires KernelSU root approval.
Keep the published APK signer when upgrading. No reboot or fresh login is
requested by this update.

## Verification

On the connected rooted ARM64 phone, the real Material Files share flow displayed
the rounded sheet with the file manager visible behind it. English/Chinese
switching refreshed the open share sheet; language and confirmation choices
persisted. Optional confirmation showed a review step, while the default sent
directly. Receive-notification settings opened Android's settings page. Settings
was inspected in light/dark themes and landscape.

Phone-to-Mac transfers of a UTF-8 text file and a 512 MiB binary matched SHA-256.
Live notifications showed changing sent/total bytes and MB/s. Installing the
verified ARM64 module ZIP preserved the node ID, IPs and exact Tailscale
preferences after startup convergence; a peer ping succeeded without reboot.

The pure-Java progress regression covers stalls, file resets, unknown/zero and
inconsistent totals, and counters above 2 GB. All three module ZIPs passed package
validation. GitHub Actions enforces the release build, signing, immutable assets
and package checks before publication.

32-bit ARM device coverage, every document provider, long-term battery behavior
and Android's six-hour foreground-service limit are not established. This is not
an official Tailscale or KernelSU release.
