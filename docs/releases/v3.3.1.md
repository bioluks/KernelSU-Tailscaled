# KernelSU-Tailscaled v3.3.1 — Fix KernelSU upgrade stop timeout and process race

This patch release fixes an in-place upgrade failure (`KernelSU-Tailscaled: current-stop-failed`)
encountered when updating the module through KernelSU / KernelSU-Next Manager without rebooting.

## Root Cause & Fixes

1. **Immediate SIGTERM response for supervisor:** Android's `/system/bin/sh` (mksh) blocks trap
   execution while an external command like `sleep` runs in the foreground. By shifting supervisor
   delays into background jobs monitored with `wait`, the supervisor now terminates within milliseconds
   upon receiving `SIGTERM`.
2. **Generous stop timeout during upgrade:** Exported `KST_STOP_TIMEOUT=6` (up from 3s) during candidate
   activation, giving older running generations sufficient time to complete their sleep cycle and
   exit gracefully.
3. **Bounded process exit verification:** Added a bounded retry loop to `stop_owned` when checking
   process disappearance, preventing race conditions where `/proc/$pid` is inspected while the OS
   kernel is mid-teardown.
4. **Graceful stop retry:** `activate-runtime.sh` now retries stopping the previous generation after a brief
   pause before failing the installation.

## Install

- `KernelSU-Tailscaled-v3.3.1.zip` — Universal (ARMv7 and ARM64).
- `KernelSU-Tailscaled-arm64-v3.3.1.zip` — ARM64 only.
- `KernelSU-Tailscaled-arm-v3.3.1.zip` — 32-bit ARMv7 only.
- `KernelSU-Tailscaled-companion-v3.3.1.apk` — optional Android 8.0+ companion.

Install via KernelSU / KernelSU-Next Manager directly over existing installations.
Version code **30030001** upgrades v3.3.0 and all prior versions.
