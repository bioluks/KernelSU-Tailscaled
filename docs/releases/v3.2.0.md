# KernelSU-Tailscaled v3.2.0 — Native Android compatibility

This release fixes an old-kernel networking failure without occupying Android's
VPN service slot. It retains the root-module daemon and optional companion;
LSPosed and VpnService are not required.

## Fixes

- **Older kernels:** retry read-only route netlink setup without optional strict
  socket options only when the kernel returns `ENOPROTOOPT`. Supporting kernels
  keep strict behavior; permission and other genuine failures remain errors.
  No device-name, kernel-version or Wi-Fi-interface allowlist is used.
- **Android DNS:** control-server cached lookups and standalone CLI commands use
  Android's system resolver when appropriate, rather than assuming that
  `/etc/resolv.conf` exists. No public DNS server is hard-coded.
- **Fresh identities:** hostname and conservative DNS/route defaults survive
  daemon restarts before the first authenticated profile is persisted. Existing,
  logged-out and migrated identities retain their user preferences.

## Engine provenance and updates

The engine is built from **Tailscale 1.104.2 with small Android compatibility
patches**, not distributed as an unmodified official Tailscale binary.
[Source, patches and reproducible build instructions](../../engine/README.md)
are included in this repository. Installed `engine-build.json` records the
upstream commit/archive hash, patch hashes, Go toolchain and output hashes.

**Engine updates now arrive through full module updates.** The module blocks
standalone engine replacement and the engine's own updater is compiled out, so
an official tarball update cannot silently remove the compatibility fixes.
The WebUI still shows upstream release information for reference.

Previously downloaded engines are not deleted. If a newer engine was selected,
installing an older compatibility engine is rejected before the current runtime
is stopped. Use a compatibility module with an equal or newer engine; do not
force an engine downgrade against its state.

## Install

- `KernelSU-Tailscaled-v3.2.0.zip` — ARMv7 and ARM64.
- `KernelSU-Tailscaled-arm64-v3.2.0.zip` — ARM64 only.
- `KernelSU-Tailscaled-arm-v3.2.0.zip` — 32-bit ARMv7 only.
- `KernelSU-Tailscaled-companion-v3.2.0.apk` — optional Android 8.0+ companion.

Install over the current module and app; **do not uninstall or delete state
first**. Version code **30020000** advances v3.1.0 and local compatibility builds
30010001–30010003. The APK retains the existing release signer. Normal upgrades
do not request a reboot or new login. Grant the companion its own root access.

English remains the default, Simplified Chinese remains available, Headscale is
supported, and automatic Taildrop receiving remains module-owned. No second
daemon or connection is introduced by the companion.

## Verification and limits

The preceding v3.1.1-dev.3 candidate has the same engine/runtime/app source;
v3.2.0 changes release metadata and documentation. On Poco F1 (beryllium),
crDroid Android 15, KernelSU Next and Linux 4.9.337:

- Native LAN Headscale registration and direct UDP peer connectivity passed,
  without a proxy, AFWall, route-injection scripts or disabling SELinux.
- Real companion background sends, automatic receives and duplicate-name
  handling matched SHA-256. A 32 MiB ordinary TCP download over native TUN also
  matched. Receiving worked with the companion force-stopped.
- Restart, hot upgrades and an authorized reboot retained node identity,
  tailnet addresses and exact projected preferences. Boot reconnected without
  a manual start, including recovery after Wi-Fi acquired a new LAN address.
- The CLI self-update command and daemon installation endpoint are unavailable.
- Engine tests passed on modern Linux; ARMv7/ARM64 binaries reproduced
  byte-for-byte across macOS/Linux. Module ZIPs were reproducible and passed
  architecture, payload, installed-bundle and provenance validation.

[Detailed device evidence](../verification/2026-11-17-f1-native-compatibility.md)
includes the original defect, candidate hashes and focused regression results.
The GitHub release pipeline repeats the full build, test, signing and immutable
publication gates for the release artifacts.

This is not certification of every device. ARM32 hardware execution, the patched
build on the OnePlus, cellular handover, IPv6-only networks, concurrent third-party
VPNs and long-duration screen-off/battery behavior remain unverified. Supported
ARM hardware, root permissions, kernel TUN and functioning Android networking are
still required. This is not an official Tailscale or KernelSU release.
