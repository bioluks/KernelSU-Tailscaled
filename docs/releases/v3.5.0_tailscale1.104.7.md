# KernelSU-Tailscaled v3.5.0_tailscale1.104.7 — Opt-in system-wide DNS through Tailscale

## What changed

- **Opt-in system-wide DNS.** `control.sh enable-system-dns` (or the new WebUI toggle) redirects Android's TCP/UDP port-53 queries from other processes to the tailnet nameservers delivered by the coordination server, so every app uses MagicDNS and the tailnet DNS without occupying Android's VPN slot. Queries are source-NATed to the node's tailnet address on egress, because tailnet resolvers ignore non-tailnet source addresses (such as carrier CGNAT addresses).
- **Owned netfilter chains.** The redirect lives in the module's own `KST_SYSDNS` chains, jumped from `OUTPUT` only while the daemon runs. `tailscaled`'s own egress is excluded by its socket mark (`0x80000/0xff0000`), since Android's `netd` runs as root and a uid exclusion would also skip Android's resolver. Loopback and the resolver itself are excluded; LAN, carrier and public resolvers are overridden, which is the point of enabling it.
- **IPv6 handling.** Kernels with IPv6 NAT get an equivalent redirect. Kernels without it reject IPv6 port 53 instead of silently leaking carrier IPv6 resolvers, so lookups fall back to the redirected IPv4 path.
- **Safe lifecycle.** Rules are applied only when enabled and the daemon is running, refreshed after a daemon restart, removed when the daemon stops, the feature is disabled, or the module is uninstalled. When the feature has never been enabled, no netfilter command runs at all.
- **Truthful status.** The expected Android `/etc/resolv.conf` write failure is now translated into an accurate info diagnostic instead of a misleading health warning. The status JSON gains `systemDns: {enabled, applied}`.

## Enable

From a root shell:

```sh
sh /data/adb/modules/kernelsu-tailscaled/control.sh enable-system-dns
sh /data/adb/modules/kernelsu-tailscaled/control.sh disable-system-dns
```

Or use **Use Tailscale DNS for all apps** in the WebUI Network section. The
toggle requires a running daemon and a tailnet DNS nameserver; enabling first
sets `--accept-dns=true` and probes both a public name and the node's own
MagicDNS name through the chosen resolver.

## Limits

- Set Android **Private DNS** to **Off** — DoT on port 853 bypasses port-53 rules.
- Apps with built-in DNS-over-HTTPS (some browsers) bypass the redirect; disable
  their secure-DNS option if you need them covered.
- The tailnet must have a global nameserver configured, otherwise the internal
  resolver can only answer MagicDNS names and the enable probe refuses. The
  probe also requires the resolver to answer MagicDNS names.
- Do not combine with other DNS modules; they may add competing rules. Enabling
  refuses while another port-53 redirect is active, and the status warns when a
  dormant DNS module is installed. This module never modifies rules it does not
  own.

- `KernelSU-Tailscaled-v3.5.0_tailscale1.104.7.zip` — Universal (ARMv7 and ARM64).
