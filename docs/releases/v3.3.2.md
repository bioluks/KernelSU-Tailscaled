# KernelSU-Tailscaled v3.3.2 — Live upgrade handoff and DNS safety

- Older runtimes get a six-second shutdown allowance during upgrade handoff. Ordinary shutdown and rollback retain their three-second default, and process ownership checks remain in place.
- Manager status distinguishes an update that is only staged from a running runtime still awaiting KernelSU promotion. The WebUI clarifies that applying a staged runtime does not promote Manager metadata.
- The DNS toggle leaves preferences unchanged if the current `CorpDNS` setting cannot be read. Explicit enable and disable actions still work.

## Install

Flash over the existing installation in KernelSU or KernelSU-Next Manager. Do not uninstall or clear state. Version code **30030004** upgrades v3.3.1 and both local v3.3.2 test builds.

- `KernelSU-Tailscaled-v3.3.2.zip` — ARMv7 and ARM64
- `KernelSU-Tailscaled-arm64-v3.3.2.zip` — ARM64 only
- `KernelSU-Tailscaled-arm-v3.3.2.zip` — ARMv7 only
- `KernelSU-Tailscaled-companion-v3.3.2.apk` — optional Android 8.0+ companion

The runtime can switch immediately while Manager still offers a reboot. Check **Current runtime** in the WebUI to see which version is selected.
