# KernelSU-Tailscaled v3.4.0_tailscale1.104.7 — Tailscale 1.104.7 engine and companion landing redesign

## Engine

- The bundled engine is upgraded from Tailscale 1.104.2 to **1.104.7**, built from pinned upstream source (`cbc74fe48ef1b1649f69a4d9a602319427e25102`, archive SHA-256 `fa1c922b33d0f6db6b073800d7a62fa84081323d247b21547c63a98ed7ecac14`) with the same two reviewed Android compatibility patches applied unchanged.
- The two patches apply to 1.104.7 without modification. The Go toolchain pin moves to go1.27.4, required by the new upstream `go.mod`.
- Both ARMv7 and ARM64 CLI and daemon binaries were built twice in the pinned container and are byte-identical across builds. The engine regression packages (`net/netmon`, `net/dnscache`, `feature/androiddns`, `net/dns`, `cmd/tailscale`) pass on 1.104.7.
- `files/engine-build.json` records the new upstream commit, archive hash, toolchain, patch hashes, and output hashes; `files/manifest.sha256` was regenerated and verifies.

## Versioning

- Module versions now embed the bundled engine: **`3.4.0_tailscale1.104.7`**. `versionCode` stays a single monotonic integer (`30040000`), which KernelSU uses for update ordering.
- A metadata test now enforces that the module version and the public feed version carry `files/VERSION.txt`, the single source for the engine version in the build (`scripts/build_engine.py` constants and the generated files).

## Companion

- The landing screen matches the settings and send screens: edge-to-edge background, app bar with module icon, a module-status card with refresh, enable/disable/restart actions, and tool rows (full panel, logs, send files, settings) using the same cards and typography.
- Shared helpers (`Ui`) now hold the duplicated text/card/heading/dp code; the settings screen uses them unchanged.
- Root commands try known `su` locations (`/data/adb/ksu/bin/su`, `/data/adb/ap/bin/su`, `/su/bin/su`, `/system/xbin/su`, `/system/bin/su`) before falling back to PATH lookup.

## Install

- `KernelSU-Tailscaled-v3.4.0_tailscale1.104.7.zip` — Universal (ARMv7 and ARM64).
- `KernelSU-Tailscaled-arm64-v3.4.0_tailscale1.104.7.zip` — ARM64 only.
- `KernelSU-Tailscaled-arm-v3.4.0_tailscale1.104.7.zip` — 32-bit ARMv7 only.
- `KernelSU-Tailscaled-companion-v3.4.0_tailscale1.104.7.apk` — optional Android 8.0+ companion.

Install via KernelSU / KernelSU-Next Manager directly over existing installations. Version code **30040000** upgrades v3.3.2 and both local v3.3.2 test builds.
