# KernelSU-Tailscaled v3.3.0 — Live Tailscale DNS on/off switch

This release adds a live **Tailscale DNS on/off switch** directly to the module WebUI,
allowing users to quickly toggle Tailscale MagicDNS / CorpDNS acceptance on the fly
without needing CLI commands, daemon restarts, or device reboots.

If a defined upstream DNS server (such as an AdGuard Home instance or custom DNS server
on a Headscale/Tailscale network) goes down, users can immediately toggle off Tailscale DNS
from the WebUI to fall back to their local Wi-Fi or cellular DNS without losing connectivity
to the rest of their tailnet peers.

## Highlights & Features

- **Live WebUI switch:** Under the **Network** section in the KernelSU WebUI, an interactive
  toggle button (`Disable Tailscale DNS` / `Enable Tailscale DNS`) allows instantaneous switching.
- **Direct CLI control actions:** Module management commands now support:
  - `control.sh enable-dns` — Accept Tailscale DNS configuration.
  - `control.sh disable-dns` — Stop accepting Tailscale DNS configuration.
  - `control.sh toggle-dns` — Toggle between accepting and ignoring Tailscale DNS.
- **State persistence:** Preference mutations are written directly to `tailscaled.state` and
  survive daemon restarts and device reboots.
- **Full bilingual localization:** English and Simplified Chinese are fully supported for button
  labels, announcements, and toast notifications.
- **All v3.2.0 features retained:** Built 100% from source code from upstream Tailscale 1.104.2
  with zero opaque blobs, compatibility with Linux 4.9+ kernels, Android dnsproxyd resolver support,
  and native TUN networking without occupying Android's VPN slot.

## Install

- `KernelSU-Tailscaled-v3.3.0.zip` — Universal (ARMv7 and ARM64).
- `KernelSU-Tailscaled-arm64-v3.3.0.zip` — ARM64 only.
- `KernelSU-Tailscaled-arm-v3.3.0.zip` — 32-bit ARMv7 only.
- `KernelSU-Tailscaled-companion-v3.3.0.apk` — optional Android 8.0+ companion.

Install over the current module; **do not uninstall or delete state first**.
Version code **30030000** advances v3.2.0. Upgrading does not require a reboot or re-login.
