# KernelSU-Tailscaled v3.6.0_tailscale1.104.7

## Android companion

- **Module settings** brings control server and Headscale sign-in, Taildrop destination, DNS, diagnostics, migration, and supported update controls into the app. The root manager WebUI remains available; the APK is optional.
- **Open full panel** opens the local Tailscale panel inside the app by default. Use the toolbar back arrow to return, or enable **Settings → Open full panel in browser**. If your ROM blocks the app's network access, it may also block the loopback panel; the app offers retry, Android app settings, and a browser fallback.
- **Transfer history** replaces the last-transfer text. It keeps up to 100 sent, received, failed, or cancelled entries locally, with a short preview on the landing page. **Show all → Clear** removes the history without deleting any files. Recording defaults to on and can be disabled in Settings.
- The landing page separates connection status, device addresses, and other facts from warnings and errors.

## Runtime and DNS

- The controller detaches from Android app process groups before starting the runtime so removing the root manager or companion from recents does not stop Tailscale.
- When system-wide DNS is applied, the competing DNS-rule warning can show the detected port-53 chains, rules, direct jumps, and matching script paths. The module does not change foreign rules.
- The companion and module WebUI identify strict Android Private DNS, which can bypass the port-53 redirect, and offer an explicitly confirmed **Turn Private DNS off** action. Nothing changes the Android setting automatically. Automatic mode can fall back to plain DNS; apps with their own encrypted DNS can still bypass the redirect.

## Install

| Asset | Use |
| --- | --- |
| `KernelSU-Tailscaled-v3.6.0_tailscale1.104.7.zip` | Universal module ZIP (ARMv7 and ARM64) |
| `KernelSU-Tailscaled-arm64-v3.6.0_tailscale1.104.7.zip` | ARM64-only module ZIP |
| `KernelSU-Tailscaled-arm-v3.6.0_tailscale1.104.7.zip` | ARMv7-only module ZIP |
| `KernelSU-Tailscaled-companion-v3.6.0_tailscale1.104.7.apk` | Optional companion, Android 8.0 or newer |

Upgrade the module in your root manager using one ZIP. Update the optional companion separately with the release-signed APK. A debug-signed APK cannot be upgraded in place with the release signer. Version code **30060000** supersedes v3.5.0; the bundled Tailscale engine remains **1.104.7**.
